# �️ LandLock System

A secure, accessible land registry system built to prevent fraud and double-selling of land in Malawi.

Designed for real-world impact — works on smartphones **and** basic phones via USSD/SMS.

---

## 🎯 Key Features

- ✓ Register land using phone GPS (no native app needed)
- ✓ Multi-party approval (owner, chief, witness)
- ✓ Works without internet (USSD/SMS support coming)
- ✓ Tamper-evident audit log
- ✓ Mobile-first UI with Tailwind CSS
- ✓ Clean separation: frontend (SvelteKit), backend (Flask), database (Supabase)

Built as a portfolio project focused on solving problems in developing nations.

---

## ⚙️ Tech Stack

| Layer       | Tool |
|------------|------|
| Frontend   | SvelteKit + Leaflet + Tailwind CSS |
| Backend    | Python + Flask |
| Database   | Supabase (PostgreSQL) |
| Hosting    | Vercel + Railway (future) |
| SMS/USSD   | Africa’s Talking API |
